# Sam-DataLens

**Chat with your data.** Ask a question in plain English and get back a chart and a business-ready insight — no SQL required.

Sam-DataLens is a natural-language analytics tool. You type *"show me revenue by region"* or *"what's the profit trend over time?"*, and it returns the right visualization (bar / line / pie / KPI) plus a concise, data-grounded narrative written by an LLM.

> Live insight generation is powered by **Groq** (OpenAI-compatible API). Without an API key the app still runs fully — it falls back to a deterministic analytics engine — so the demo never breaks.

---

## Features

- **Natural-language → chart.** A deterministic query engine maps questions to real aggregations over the dataset and picks an appropriate chart type.
- **LLM-written insights.** When a `GROQ_API_KEY` is set, each answer's narrative is generated by Groq from the *actual* numbers returned — never hallucinated figures.
- **Safe SQL path.** For the live-database mode, generated SQL is parsed to an AST and validated **SELECT-only with an enforced row limit** (`src/lib/sqlValidator.ts`) before it could ever run.
- **Auth + saved queries.** Credentials auth via NextAuth; save and revisit past queries (Prisma + PostgreSQL, with a graceful in-memory fallback when no DB is configured).
- **Light/dark theme**, responsive UI, built on Next.js App Router.

## Getting Started

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev
```

Open http://localhost:3000.

### Environment variables

See `.env.example`. The only one needed for the AI insights is:

```env
GROQ_API_KEY=your_groq_key   # free key at https://console.groq.com
NEXTAUTH_SECRET=some_random_string
NEXTAUTH_URL=http://localhost:3000
```

`DATABASE_URL` is optional — leave the placeholder and the app runs in demo mode (login and saved-queries fall back to in-memory behaviour).

---

## How it works

1. The browser posts your question to `POST /api/chat`.
2. `DataLensEngine` (`src/lib/engine.ts`) computes the real aggregated result set and chart specification — this is the source of truth for every number shown.
3. If Groq is configured, `InsightGenerator` (`src/lib/ai/insightEngine.ts`) turns those numbers into a short analyst-style narrative. On any failure it silently falls back to the engine's own insight.
4. The response (`insight`, `data`, `chartType`, …) is rendered with Recharts.

## Deploy

Deploys to Vercel as a standard Next.js app. Set `GROQ_API_KEY`, `NEXTAUTH_SECRET`, and `NEXTAUTH_URL` (and optionally `DATABASE_URL`) as project environment variables.
